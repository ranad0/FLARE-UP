# Original work preserved
`original_backend` is a reference snapshot of the Python modules from the supplied FLARE_UP_COMPLETE archive. It is not imported by the running app. The active app preserves the three routing paths and extends the original structured parser; see docs/ARCHITECTURE.md.

The Dext observation file is the supplied model/experiment regression fixture. It remains available to tests and audit. NASA classifies PSI-117 as Ground Investigation, so this fixture is deliberately not loaded into the judged corpus. Historical unverified labels inside archived files reflect their original state, not the current classification.
