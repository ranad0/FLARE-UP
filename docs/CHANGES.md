# Audit and changes

## Baselines
`FLARE_UP_COMPLETE.zip` supplied the usable FastAPI backend: question routing, structured query parser, MiniLM embedder, local JSON vector store, API contracts and legacy Dext regression data. These remain traceable in `legacy/original_backend` and the active compatibility modules.

`Fireline-source-v17.zip` provided the minimal search-first visual reference, but its standalone answer content was not a replacement for the real backend. Its old name is not the final product name.

The supplied `flare-up ai google studio lab simulator.zip` was the strongest frontend implementation base: React/TypeScript, English/Arabic navigation and an actual Three.js lab. Its code was integrated locally; the final app does not depend on AI Studio or Gemini. Chrome was used to inspect the supplied AI Studio preview and NASA resources.

## Implemented
- FLARE UP branding throughout the active UI; matching SVG spherical flame mark/favicon with blue, lilac and amber.
- Minimal search-first violet/cream homepage, subtle stars, eased cursor-responsive flame, reduced-motion support.
- Retained 3D lab, refined flame geometry/shader and chamber visibility; material, gravity, oxygen, pressure and airflow controls; stale evidence cleared when conditions change.
- Real FastAPI connection for ask/scenario/measurements, explicit error handling and source links.
- Searchable investigation coverage, source-row numeric comparisons, supporting NASA resource search.
- Expanded microgravity-only PSI snapshot, provenance hashes and review/exclusion ledgers; legacy ground Dext fixture retained outside judged retrieval.
- Original three routes and response fields retained; source-specific structured filtering expanded.
- Local extractive default eliminates paid-provider dependency. Original MiniLM embedding option preserved separately.
- Build, scientific integrity tests, HTTP integration tests and run/deploy documentation.

## Optional next work
- Validate/install the preserved MiniLM option or add an independently tested local synthesis model if richer prose is wanted. Current answers are extracted evidence, not generated explanations.
- Human scientific review of remaining report extraction and ambiguous units. 2,737 records have unknown units; 258 FLEX burning-rate fields carry a source dimensionality concern.
- Ingest selected large video archives only after choosing meaningful analysis goals/storage. The manifests list terabytes; those videos are not included.
- Calibrate a quantitative scenario model against matched experimental conditions. Current Fire Lab is an illustrative exhibit, never a safety predictor.
- Translate scientific content professionally; current Arabic UI keeps original English source text.
- Choose a hosting account, final team details and public submission URL. Nothing has been published to GitHub or a hosting account.
